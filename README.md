# SS Family Travel Console

公開、唯讀的家庭旅行參考頁面，顯示由使用者指定正式版行程同步而來的去識別化摘要、特色與歷史介紹、行程庫候選項目、官方參考來源、公開 Google Maps 導航連結，以及 Leaflet + OpenStreetMap 方位地圖。

## 隱私與公開範圍

這個公開版本刻意不含姓名、聯絡方式、訂位／票券識別碼、住宿細節、付款資料、個別文件連結、帳號、憑證或內部來源識別資訊。經使用者明確核可的例外，是「私人文件捷徑」中的五個 Google Drive **分類資料夾**連結；這些連結位於公開網站，具有曝光風險，必須使用已獲授權的 Google 帳號登入，且不得轉傳。本站不嵌入、下載或鏡像 Drive 文件，也不變更 Drive 分享權限。

正式版同步只保留日期、地區、活動順序、公開導航與狀態；來源試算表中的住宿名稱／地址、訂位代碼、價格、保險、財務與私人接送資料均不會進入公開快照。住宿捷徑的資料夾可能含取消紀錄，請以最新 Notion／確認信為準。

內容為旅行方位參考，並非即時交通、天氣、道路、營業或預訂狀態。候選、備案與待確認項目不代表最終行程。

